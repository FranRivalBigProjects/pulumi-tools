Pulumi Cloud pricing by edition

Pulumi replaced its old per-user plan with credits. One credit costs $1 and every billable unit draws from the same pool. Each paid edition charges a monthly base fee that creates the pool; if you use more, the overage is billed in arrears at the same rates.

Does this match what you saw before?

Older articles mention $0.0005 per credit, 150,000 free credits per month, or a flat $50 per user. Those describe previous Team and Starter plans. The calculator above uses the current Free, Essentials, Pro and Enterprise structure.

How Pulumi counts billable resources

  • Everything declared counts. Provider resources (an S3 bucket), component resources (an EKS cluster grouping) and the stack itself.
  • Billing is hourly. A partial hour is billed as a full hour, so short-lived preview stacks cost proportionally less than permanent ones.
  • Real examples from Pulumi: a serverless API on API Gateway and Lambda is about 9 resources, EKS in a VPC about 20, ECS with RDS in a VPC about 24.

To count your own, open the "Resource Count over Time" graph in the Pulumi Cloud dashboard. With a DIY backend, export the state and count the URNs:

pulumi stack export | grep -c '"urn"'

Using Pulumi for free

Pulumi Cloud Free. One user, automatic state management, Deployments, basic ESC, unlimited projects, stacks, updates and history, and no cap on managed resources. It does not include Neo, Resource Search or Property Search.

Open source with your own backend. The CLI and SDK are open source. Store state in your own bucket and pay only for storage:

pulumi login s3://my-state-bucket # AWS pulumi login gs://my-state-bucket # Google Cloud pulumi login azblob://my-container # Azure

The trade-off is that you manage state, locking and secrets yourself and lose the Pulumi Cloud UI, Deployments, drift detection and ESC.

Beyond the included credits, an IaC resource costs $0.1825/month on Essentials, from $0.365 on Pro and from $0.5475 on Enterprise.
