Infracost + Pulumi — automated cost estimation

Infracost is the most popular open-source tool for estimating infrastructure costs from IaC code. It supports Pulumi (TypeScript, Python, Go, .NET) and integrates into CI/CD pipelines.

# ─── INSTALL INFRACOST ─── brew install infracost # macOS # or: curl -fsSL https://raw.githubusercontent.com/infracost/infracost/master/scripts/install.sh | sh # ─── REGISTER (FREE API KEY) ─── infracost auth login # ─── ESTIMATE PULUMI STACK COSTS ─── cd my-pulumi-project/ infracost breakdown --path . # ─── PULUMI PREVIEW + INFRACOST DIFF ─── infracost diff --path . --compare-to infracost-base.json # ─── OUTPUT FORMATS ─── infracost breakdown --path . --format json --out-file estimate.json infracost output --path estimate.json --format html --out-file report.html # ─── GITHUB ACTIONS CI/CD INTEGRATION ─── # Add to your workflow — shows cost diff on every PR uses: infracost/actions/setup@v3 with: api-key: ${{ secrets.INFRACOST_API_KEY }}

Infracost for Pulumi

Open source. Supports TypeScript, Python, Go, C# Pulumi programs. Shows cost per resource. Integrates with GitHub, GitLab, Bitbucket PRs. Shows cost diff before merge. Free tier: 150 runs/month.

Pulumi Cloud Cost Integration

Pulumi Cloud (Team plan+) shows cost estimates inline in the Pulumi UI after deploying. Uses cloud provider billing APIs. Less granular than Infracost pre-deployment — better for post-deployment tracking.

Pulumi pricing guide

Is Pulumi free? What does the free plan include?
Yes — Pulumi's IaC engine is fully open source and free. You can deploy, update, and destroy infrastructure without paying anything. The free Individual plan on Pulumi Cloud includes unlimited stacks, 200 managed resources in Pulumi Cloud state, 1 user, 500 deployment minutes/month, and community support. For state storage, you can use your own S3 bucket, GCS bucket, or Azure Blob Storage as a free backend instead of Pulumi Cloud entirely.

When does the Team plan make sense?
The Team plan ($50/user/month, $40 billed annually) adds: unlimited resources in Pulumi Cloud, team collaboration with RBAC, OIDC for GitHub Actions/GitLab CI, secrets management, deployment history, and SAML SSO. It pays for itself when you have 2+ engineers who need to share state and collaborate on stacks. If you use a self-managed backend (S3/GCS), you avoid Pulumi Cloud costs entirely but lose deployment history, drift detection, and the team UI.

Self-hosted backend — the free alternative
Store Pulumi state in your own S3 bucket: pulumi login s3://my-state-bucket. This gives you unlimited resources, unlimited team members (for state only), and full control — at no cost beyond S3 storage (~$0.02/GB/month). The tradeoff: no Pulumi Cloud UI, no deployment history, no drift detection. Teams using Terraform state in S3 already know this pattern — it works identically for Pulumi.

FAQ — Pulumi cost estimation
Pulumi has three tiers: Individual (Free) — open source IaC engine, 200 resources in Pulumi Cloud, 1 user. Team — $50/user/month ($40 annual), unlimited resources, RBAC, OIDC, SAML SSO, deployment history. Enterprise — custom pricing, self-hosted option, audit logs, compliance controls. The IaC engine itself is always free. You pay for Pulumi Cloud features: state management, team UI, and deployment automation.

Add it to CI/CD (GitHub Actions, GitLab) to show cost diffs on every pull request before infrastructure changes are applied.
